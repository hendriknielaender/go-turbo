# Privacy

`go-turbo` is a skills-only plugin. It does not operate a server, create an
account, collect telemetry, set cookies, or transmit repository contents to a
service controlled by this project.

The skills provide instructions to the host coding agent. Any files, commands,
network access, model processing, diagnostics, or telemetry used while running
those instructions are controlled by the selected host and the user's own
environment, permissions, and provider terms.

Do not include secrets, credentials, personal data, or proprietary source code
in a public issue. Privacy questions can be raised through the repository's
issue tracker.
